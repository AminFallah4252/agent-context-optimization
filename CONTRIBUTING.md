# Contributing to Agent Context Optimization Directives

Thank you for your interest in improving and expanding context management rules for AI coding agents!

## How You Can Contribute

1. **New Agent Adapters**: Provide optimized rule sets for other IDEs and agent harnesses (e.g., Aider, Continue.dev, Copilot Workspace, Devin-style harnesses).
2. **Refining Thresholds**: Propose improved heuristics or empirical benchmarks for token thresholds, file count limits, or alert triggers.
3. **Case Studies & Examples**: Add real-world engineering examples to `docs/EXAMPLES.md`.

## Guidelines

- Keep rule directives imperative, unambiguous, and concise.
- Ensure any added adapters adhere to the 5 core principles (Artifacts-first, Subagent sandboxing, Bounded I/O, Milestone checkpointing, Proactive rollover alerts).
- Open a Pull Request describing your changes and testing rationale.
